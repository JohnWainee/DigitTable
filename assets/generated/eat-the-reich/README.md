## Shared art direction

- Hand-painted pulp graphic novel with screen-print grain and rough ink edges.
- Bone paper, charcoal black, restrained crimson, electric cyan, and occasional amber.
- Original fictional people and scenes; no readable text, logos, real-person likenesses, copyrighted characters, or explicit extremist insignia.
- Anti-fascist dramatic framing without military-propaganda treatment.

The exact production prompts were recorded in the image-generation task that created these files. Preserve the source PNGs; implementation may derive responsive WebP/AVIF variants without overwriting them.

### Derivatives

WebP derivatives for all of the above (plus `campaign-hero.png`) live at `apps/web/public/etr/*.webp`, generated by `scripts/generate-etr-derivatives.sh` — **not** committed source, but not build-time-generated either: run once locally and the resulting `.webp` files are committed alongside the source PNGs. The script uses `sips` (macOS built-in) and `cwebp` (`brew install webp`), neither an npm dependency; it deliberately avoids `sharp` since that package is not in `package-lock.json` and Sonnet C does not add dependencies. See the script's own header comment for the exact commands and the reasoning, and propose `sharp` to Sonnet A if CI-reproducible derivative generation is wanted later.

Sizes produced: portraits `-512`/`-256`/`-token-128`; scenes `-1536`/`-1024` (as `scene-<id>-*.webp`) and `-640` (as `<id>-640.webp`, matching `SceneArt.tsx`'s convention); threats `-256`/`-128`; hero `-1600`/`-1000`/`-600`. All measured well under the art brief's section 4 per-image budgets (largest scene derivative 265 KB vs. a 260 KB target — 5 KB over, not worth a second encoding pass at this size).
