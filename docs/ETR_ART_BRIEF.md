## 2. Direction

**One sentence:** hand-painted pulp graphic novel about vampire commandos loose in occupied Paris — screen-print grain, rough ink edges, torn dossier paper, grease-pencil marks.

**Palette (CSS tokens, C05 wires them; the existing `:root` in `apps/web/src/styles.css` maps onto these):**

| Token | Hex | Role |
|---|---|---|
| `--bone` | `#EDE4D1` | paper ground (light), text on dark |
| `--charcoal` | `#151517` | ink, dark ground, text on light |
| `--crimson` | `#8A1F1F` (`--crimson-hot` `#C42B2B`) | Blood, injuries, criticals, primary action |
| `--cyan` | `#4FC3E8` | searchlights, focus rings, links, "live" status |
| `--amber` | `#D9A441` | lamplight, warnings, pending/waiting |
| `--ash` | `#6E6A66` | disabled, discarded dice |

Contrast targets: body text ≥ 7:1, UI text ≥ 4.5:1, non-text ≥ 3:1 in both light (bone ground) and dark (charcoal ground) themes. Crimson on bone passes; crimson on charcoal needs `--crimson-hot`.

**Type:** condensed grotesque for headings (system fallback: `Impact`-free — use `"Oswald", "Arial Narrow", system-ui` via the allowed Google Fonts stylesheet, or system condensed), humanist sans for body. No typewriter faces for body text (legibility on phones).

**Framing rules:** anti-fascist pulp drama without military-propaganda treatment; no glorified uniforms in hero shots; enemies read as masked, faceless, bureaucratic; violence is implied by aftermath and motion, never gore close-ups.

### 3.6 Route map (SVG, code-drawn) — priority 2

`RouteMap.tsx` renders an original, schematic Paris: river as a single bezier band, three concentric sector rings (outer/middle/inner) labelled 3/2/1, scene nodes as stamped circles connected by a grease-pencil route. Visual states: `upcoming` (outline), `current` (crimson fill, pulsing only when motion allowed), `cleared` (bone fill with red cross stamp). No tactical movement, no line-of-sight, no measuring. Node positions come from the scene fixture (`mapX`, `mapY` in 0–100 units). Must render legibly at 320px wide (nodes ≥ 24px) and on a 1080p table display.

## 5. Loading fallbacks and no-image play

Every image slot renders a CSS fallback that is the **default until load**, not just the error state:

- Portrait/token: charcoal circle with a bone two-letter monogram (initials from the name), crimson ring when downed.
- Scene: bone paper texture (CSS noise) with the scene title in condensed type and the sector number stamped.
- Threat: charcoal square with the `threat` glyph; crossed out in crimson when beaten.
- Hero: gradient charcoal→cyan-tinged charcoal with title.

All play information (stats, Blood, injuries, dice, ratings) is text or SVG and is never conveyed only by an image. `prefers-reduced-motion` disables the current-node pulse and the contact vignette animation.

## 6. Provenance and file hygiene

- Preserve source PNGs; never overwrite. Append every new file to `assets/generated/eat-the-reich/README.md` with tool, date, intended use, native size, and alt seed (the existing table format).
- Record the generation prompts in the same README (one line each). No prompt may reference the book, its characters, its artist, or "in the style of" any named artist.
- Derivatives are build outputs committed once (small) or generated in CI; either way, `README.md` states which.
- Add a `LICENSE-ASSETS.md` note: original placeholder art, approval required before public release (matches the existing README's caveat).
