## Pure helpers (`apps/web/src/repository/eventTail.ts`)
- `authorizedPartitions(capability): readonly EventTailPartition[]` — `player`: `["shared","member"]`; `gm`: `["shared","gm","member"]`; `table`: `["shared"]`.
- `partitionCollectionPath(roomId, partition, memberId): string` — `rooms/${roomId}/events/shared/items`, `.../events/gm/items`, `.../events/member-${memberId}/items`.
- `parseTailDocument(partition, docId, data, parseEvent)`: validates a stored envelope-shaped document and returns an `EventTailRecord`. Require: `eventId` non-empty string; `commandId` non-empty string; `sequence` safe integer >= 1 AND equal to `Number(docId)`; `roomRevision` safe integer >= 0; `payload` accepted by the supplied `parseEvent(payload)` (which throws on invalid). Any violation throws an `Error` (fail closed). The returned record MUST NOT carry `actor`, `occurredAtServer`, or any other envelope field (presentation never needs authorship) — construct it field by field.
- `assembleTailPage(perPartition: Partial<Record<EventTailPartition, readonly EventTailRecord<T>[]>>, after: EventTailCursor, limit: number)`: merges the per-partition (already ascending) results into one array ascending by `sequence` (ties: partition order gm, member, shared, then eventId). Drop defensively any record at or below `after[partition]`. WATERMARK (this is a correctness requirement — partitions page independently, so a naive merge can release sequence 91 from a full partition before another partition's sequences 51..90 were fetched): let `W` = the minimum, over partitions that returned exactly `limit` records (a "full" partition), of that partition's LAST returned sequence; if no partition is full, `W = Infinity`. Release only records with `sequence <= W`; records above `W` are WITHHELD (not returned and NOT counted in the cursor, so the next page re-reads them). `cursor` = `after` advanced per partition to that partition's last RELEASED sequence (never lower than `after`). `hasMore` = true iff any partition was full or any record was withheld.
- `clampTailLimit(limit?: number)`: default `EVENT_TAIL_PAGE_LIMIT`, clamp to `[1, EVENT_TAIL_PAGE_LIMIT]`, non-integers floored.
